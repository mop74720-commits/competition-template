# Method Cards

这里保存**当前比赛实际核验过的文献方法卡**，用于连接外部文献与当前题的模型选择。

- 一篇论文/一种独立方法建议单独一张卡；
- 明确 `FULLTEXT_VERIFIED / ABSTRACT_ONLY / METADATA_ONLY`；
- 记录方法前提、required data、迁移边界、失败模式和证据定位；
- `ADOPTED` 只表示它实际影响了当前方案，不代表文献结果可以当作当前题结果；
- 搜到但最终拒绝的方法卡也保留，避免重复踩坑；
- 文献方法和历史经验只能形成 prior/候选，不能直接写入 `problem/FACTS.md`。

新建卡时复制 `_template.yaml`。推荐由 SkillHub 的 `LITERATURE_EVIDENCE_NEEDED` / `literature-evidence` 生成或复核。
